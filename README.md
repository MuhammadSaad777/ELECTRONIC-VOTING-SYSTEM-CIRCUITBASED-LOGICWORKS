ELECTRONIC VOTING SYSTEM

OverView:

An electronic voting system made using logic works.
Used to take votes from public and display vote count for each candidate . The candidate after close of voting is declared winner.

Features:

Allowing public to vote for their favourite candidates.
Allowing candidates to track their votes as well as their enemies votes at anytime.
Display winner and in case of tie display all candidates whose votes have tied.

Technologies used:

Digital Logic Design Concepts
Circuit Analysis and Circuit Designing
Simple User Friendly interface

Project Structure:

LogicWorks .cct file contains complete logic.
Voters vote their desired candidate.
Vote Display Updates.
At end candidate with maximum votes is declared winner.

Running procedure:

1.Clone following github repository:


Open project in LogicWorks

Simulate project and run it
